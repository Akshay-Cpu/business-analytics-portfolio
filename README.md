## Reproduce the snapshot checks

With Python 3 installed, run from the repository root:

```bash
python validate_all.py
```

The scripts use the Python standard library. They check the delivered CSV snapshots; they do not recalculate Excel, regenerate the original synthetic observations or execute DAX.

Both project snapshot checks passed when this portfolio was packaged on 19 October 2026. See each project's validation notes for the scope and limits of the earlier workbook checks.
